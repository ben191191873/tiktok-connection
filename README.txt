BEFORE PUBLISHING:
1. Replace [ADD YOUR CONTACT EMAIL BEFORE PUBLISHING] in terms.html and privacy.html with a real contact address.
2. Review the Privacy Policy and make sure it accurately reflects your actual TikTok scopes, integration provider, data processing, storage, retention, and deletion arrangements.
3. Check TikTok's developer requirements for app review, domain verification, and policy URLs. A public website alone does not guarantee approval.

PUBLISH FOR FREE (example: GitHub Pages):
1. Create a public GitHub repository.
2. Upload index.html, terms.html, privacy.html, style.css, and icon.png to its root.
3. In repository Settings > Pages, select Deploy from a branch and choose main / root.
4. Wait for the public website address shown by GitHub Pages.
5. Use the homepage address for Web/Desktop URL, and the full /terms.html and /privacy.html URLs for the other fields.
